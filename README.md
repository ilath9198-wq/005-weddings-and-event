## 📐 Dedicated Navigation & Architecture (Zero `.html` Compliance)
Every section is its own distinct page route powered by Next.js App Router:
1. **Home (`/`)**: Hero, Royal Heritage, 12 Core Services, Palace Venues, Planning Roadmap, and Real Reviews.
2. **About Us (`/about`)**: Heritage backstory, design philosophy, logistical excellence, and leadership profiles.
3. **Our Services (`/services`)**: Full catalog of 12 luxury services with interactive scope modals.
4. **Wedding Venues (`/venues`)**: 7 curated heritage palaces, beach lawns, and mountain glasshouses.
5. **Wedding Planning (`/planning`)**: 9-phase wedding roadmap and milestone breakdowns.
6. **Photography & Films (`/photography`)**: Fine-art photography, 4K wedding films, pre-wedding destination sessions, and heirloom leather albums.
7. **Our Portfolio (`/portfolio`)**: 8 royal wedding celebrations with interactive full-screen image lightbox.
8. **Packages (`/packages`)**: 5 structured investment tiers, side-by-side comparison table, and FAQ accordion.
9. **Contact Us (`/contact`)**: Studios in Delhi, Udaipur, and Mumbai with interactive inquiry generator and WhatsApp link.

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/ilath9198-wq/005-weddings-and-event.git

# Navigate to project directory
cd "005-weddings-and-event"

# Install dependencies
npm install

# Start local development server
npm run dev
```

---

## 📦 Production Build

```bash
npm run build
```
Pre-renders all 9 routes as static pages without `.html` extensions.
